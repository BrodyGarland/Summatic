# Summatic

A mental math trainer. Type answers, get timed on every single one, and find out afterward exactly which kind of problem is slowing you down.

Inspired by [zetamac](https://arithmetic.zetamac.com/) — same idea, newer coat of paint, and it tells you *what* to work on instead of just leaving you with a number.

**Live:** https://brodygarland.github.io/Summatic/

## How it works

Pick which operations you want — addition & subtraction, multiplication & division, or percents & decimals — set how long you want to drill for, and go. Every answer is timed individually and tagged by category, so when the clock runs out you get a real breakdown instead of just a score.

There's also a Strategies popup with quick mental-math tricks (difference of squares, multiplying by 11, that kind of thing) and a full 20×20 times table if you just need to drill the basics.

## Running it locally

No build step, no dependencies beyond a couple of webfonts.

```bash
git clone https://github.com/BrodyGarland/Summatic.git
cd Summatic
open index.html
```

## Data

Everything lives in your browser's local storage — no account, no backend, no tracking.
